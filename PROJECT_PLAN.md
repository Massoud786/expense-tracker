# Expense Tracker

## Overview

Expense Tracker is a responsive web application designed to help users manage their personal finances more intelligently.

Unlike traditional expense trackers that simply record transactions, Expense Tracker analyzes spending habits and provides personalized recommendations to help users make better financial decisions.

The application is built primarily for personal use but is also designed so friends and family can securely create accounts and manage their own finances.

---

# Goals

The application should help users answer three important questions:

1. Where did my money go?
2. Which expenses are becoming habits?
3. How much money could I save by changing those habits?

# AI Spending Coach (Future)

The AI assistant should help users improve spending habits rather than simply recording expenses.

Examples include:

- Detect unnecessary spending patterns
- Detect frequently purchased items
- Suggest reducing purchase frequency
- Estimate monthly savings
- Estimate annual savings
- Compare current month with previous months
- Identify subscription waste
- Detect unusual spending spikes

The AI should explain WHY a recommendation is made using the user's actual financial data.
